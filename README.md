# Python Homework — Владислав Демчук

Репозиторий с домашними заданиями по Python, выполненными в рамках проекта "PDF-генератор счетов-фактур".

## Структура репозитория

### Основы Python (`basics/`)
- `variables/` — Реализация работы с переменными, типами данных и операторами.
- `strings/` — Задачи, связанные с обработкой строк и базовой работой с файлами.
- `dictionaries/` — Примеры использования словарей и множеств.
- `conditionals/` — Реализация условных конструкций (if, elif, else).

### Циклы (`loops/`)
- `for_while/` — Практика применения циклов `for` и `while`, включая `break` и `continue`.
- `exercises/` — Дополнительные упражнения по работе с циклами.

### Функции (`functions/`)
- `basics/` — Изучение основ определения и использования функций.
- `refactoring/` — Примеры рефакторинга кода с использованием функций.
- `parser_functions/` — Функции, предназначенные для парсинга данных.

### Проекты (`project/`)
- `research/` — Исследовательские модули и прототипы.
    - `invoice_analysis/` — Фаза 1-2: Анализ набора данных (например, 10 инвойсов).

### Парсер (`parser/`)
- Модули и утилиты для обработки и разбора данных.

### Архив (`archive/`)
- Содержит старые версии файлов и папок, организованных по датам, до реорганизации структуры репозитория.
